番組を探す
上下 / j k : 番組選択　PageUp / PageDown : 1画面移動
Home / End : 先頭／末尾（選択だけでは再生しません）
Enter : 選択枠を再生（ライブ画面ではライブ）
v : ライブ／タイムフリー画面切替　 l : 選択枠のライブ
e : 今回の取得状況・未取得の地域／局・日を閲覧
d : 出力機器の読み取り専用診断。Esc / d / q で閉じ、終了しない
f : 全条件編集　 / : キーワード編集　 r : 新規取得
条件のEnterで検索確定、Escで取消。キーワード・条件の各欄・保存名は←→で書記素を1つ、Home/Endで端、Backspaceで前、Deleteで次。確定前は通信しない。キーワード入力中は表示中の一覧の一致件数だけを未確定で出し、一覧は変えず取得しない。地域・分類欄のF2で名称選択。未確定の変換は扱わない。
b : 名前付き条件の保存・呼び出し（呼び出し後も検索確定が必要）
n 放送中の番組へ移動 o 選択局の条件を編集
再生する
Space : 一時停止／再開　 s : 停止　 + / - : 音量
左右 : 15秒シーク　 g : 枠内の整数秒を入力（タイムフリーのみ）
c : 公式AIチャプター。上下・ページ・Home/Endで閲覧、Enterで再生。rで再取得。
Tab : 章一覧／要約のスクロール切替（先頭1200文字まで）
章の時刻原点を照合できない場合はジャンプできません。
出力機器のエラーで止まったときは、プレイヤー欄に対処を出します。自動では再生し直しません。
出力先がないとき：「出力先がありません。OSのサウンド設定を確認し、Enterで再生し直してください」
対応形式外のとき：「対応形式外です。OSの出力設定を確認し、Enterで再生し直してください」
機器の開始や情報取得に失敗したとき：「出力機器を確認してください。OSの出力先を見て、Enterで再生し直してください」
スリープ復帰・機器変更後に出力が止まったとき：「スリープ復帰・機器変更後は出力先を確認し、Enterで再生し直してください」
どの対処も次の行は「自動再開はしません」。次に再生するか Esc まで残り、ライブ画面では現在の放送枠を選んでください。
再生が続いているあいだは「再生を停止しました」を出しません。
フッターの通知は1件です。種類から重要度を決め、高い方を出し、同じときは新しい方を出します。エラーは赤の太字で先頭に✕、警告は黄色で先頭に!、情報は通常の色です。警告は時間では消えず次のキーで消えます。エラーは次の操作まで残ります。情報は5秒または次のキーで消えます。キーワードと条件の入力中は、文字を打ってもエラーは消えません。消えるのは Enter と Esc だけです。エラーの下に隠れた警告は、エラーが消えてから表示され、その次のキーで消えます。NO_COLOR が空でないときは色を付けません。
終わった番組への切り替えは「番組は終了しています。再生は続いています」。
切り替え時の出力診断が時間を超えたときは「切り替えられませんでした。再生は続いています」。
再生中に次の準備が失敗したときも「停止しました」は出さず、音声が届かなければ「切り替え先の音声が届きませんでした。再生は続いています」、配信が途中で終われば「切り替え先の配信が途中で終わりました。再生は続いています」、位置が範囲外なら「指定した位置は番組の範囲外です。再生は続いています」、配信の取得に失敗すれば「切り替え先の配信を取得できませんでした。再生は続いています」、それ以外は「切り替えられませんでした。再生は続いています」。
再生が続いているあいだは、これらの文に「再生準備失敗（現在の状態を維持）」も「再生切替失敗（現在の状態を維持）」も付けません。

認証と終了
I : ログイン入力　 O : ログアウト確認　 a : セッション再確認
未ログインは「未ログインです。I でログイン」。二つのキーを並べる案内は「a で再確認 / I で再ログイン」の順です。
セッション失効は「セッション失効。a で再確認 / I で再ログイン」。
認証期限切れで止めた通知は「認証期限切れのため再生を停止しました。a で再確認 / I で再ログイン」。
プレイヤー行は、ログアウト前が「停止中：認証期限切れ（a で再確認）」、ログアウト後が「停止中：認証期限切れ（I で再ログイン）」です。
ログアウトはyで確定、n / Esc / qで取消。パスワードは表示・保存しません。
通常画面のq、またはCtrl+Cで終了します。通常画面のEscは出ている通知を消す。このEscでは終了案内を出さない。通知がなければ「終了は q（または Ctrl+C）」を出し、もう一度Escで消す。停止文・受信待ち・再接続中は案内に替えない。再生・一時停止・選択・条件は変えません。
操作一覧を開いている間も検索・再生は継続します。
